# Ledger — Expense Manager

A standalone expense tracking website. No build step, no dependencies — just one HTML file.

## Run locally
Just open index.html in your browser, or serve it:
```
npx serve .
```

## Deploy for free
See the step-by-step guide provided in chat for deploying to Vercel.

## Data & backups
Data is saved in your browser's localStorage — it persists across restarts but stays
on that one device/browser. Use the Backup / Restore buttons in the app to export
your data as a .json file and move it between devices or keep a copy somewhere safe.
